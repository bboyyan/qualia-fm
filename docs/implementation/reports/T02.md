**User-visible behavior:**
- 手機優先 AppShell：品牌＋**可點的 MOCK 徽章**（開啟「播放環境」sheet，內容為 server 真實 capabilities）、單一捲動容器、三個有文字的底部 tab（開台／收聽／設定，`aria-current`）、safe-area、`100dvh`、主欄最大 480px；桌面 ≥1100px 附說明欄，控制層級不變。
- 開台：segmented（感覺／歌曲／聲音，radiogroup＋方向鍵）、textarea（Enter 換行、IME composing 不送出、grapheme 計數 0/500、超過顯示錯誤並保留輸入）、歌曲模式加藝人欄、範例 chip 只填入不生成、CTA 空白時 disabled。
- BottomSheet：原生 modal `<dialog>`（focus trap、背景 inert）、48px 關閉鍵、Escape／backdrop／Back 都可關閉、關閉後焦點回到觸發鍵；一次只有一層。
- Toast（info／undo，5 秒）在有 sheet 時渲染於 sheet 內，Undo 仍可點；InlineRecovery 供需要操作的錯誤使用。
- 收聽頁空狀態有「去開台」下一步；設定頁 DJ 開關（`role=switch`，存 localStorage）、串詞長度、語音聲線（MOCK 提示音）、播放環境、清除本機設定。
- visualViewport 偵測鍵盤升起時隱藏底部導覽，CTA 不被遮。
