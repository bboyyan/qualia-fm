# BRA-156：開台種子選單同步我的歌

基底：`origin/main` `6b2b853`。僅整合開台草稿／UI 與既有 taste API；無伺服器、帳本格式或部署變更。交由 Sylphy 審查。

## 決策

D-39：帳本 pinned 或評價「愛」可作種子，blocked 優先排除所有來源。新候選不自動勾選，純帳本候選放在收合的「我的歌」；取消勾選只影響本輪草稿、不寫帳本。移除帳本來源須到我的歌取消釘選／收藏；兩者皆解除後消失，原先的預設／手動來源則保留。對帳本候選手動按加入，只勾選既有列。

同曲比對沿用 `trackKeyOf` 的 NFKC＋小寫＋壓空白；請求只帶使用者選取的曲名與藝人文字。每次重開／重整重新讀取，套用時讀取最新草稿以保留等待期間的輸入；切頁會取消舊讀取，失敗提示並可重試。

- **V1**：`apps/web/test/seedList.test.ts` 驗證 pinned／愛納入候選、不自動勾選、選取後 `toPlanRequest` 輸出正確。`e2e/my-songs.spec.ts` 的 BRA-156 案例用真 taste API／MOCK 節目寫帳本，從我的歌釘選後回開台可選、送出正確曲名／藝人，Ready 可見。
