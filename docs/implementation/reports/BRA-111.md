## 2. 行為變更（給審查者）

- **新 env `SPOTIFY_OWNER_USER_ID`**：唯一可成為擁有者的 Spotify 帳號 id（非秘密、區分大小寫）。未設定：伺服器可啟動，但 login 一律導回 `?spotify=unconfigured`。`SPOTIFY_ENABLED=true` 時格式明顯錯誤（空白、斜線等，不符 `^[A-Za-z0-9._-]{1,128}$`）拒絕啟動，錯誤只點名變數。
- **新連結結果**：`?spotify=account`（不是設定的擁有者帳號）、`?spotify=unconfigured`（未設定擁有者帳號）；網頁各有文案。
- **`/v1/me`**：只在連結完成時呼叫一次，只讀 `id`；名稱、email 不保存、不寫日誌，日誌也不記 id（只記 `spotify_link_wrong_account` 或 `spotify_me_failed` 與狀態碼）。
- **擁有者 cookie**：`qfm_spotify_owner`（HttpOnly、SameSite=Lax、Path=/、Max-Age 180 天、HTTPS 時 Secure）。綁裝置憑證不綁 session。
- **相容性**：BRA-111 前的 token 檔沒有擁有者雜湊 → 視為未連結。從未啟用，影響為零。
- **曲目卡**：官方 logo 改成同源靜態 PNG（51 KB，原檔未縮放以保留可比對性），CSP 不需變更；新增「顯示完整曲目資訊／收合曲目資訊」按鈕。
- **既有測試預期改變（前一輪，有意）**：`spotifyPlayback` 別的 session 由 404 變 403；`spotifyAuth` PKCE 改由同一擁有者連結兩次；`spotifyRace` 6 案加 500ms 穩定時間；`spotifyTokenStore` 帶 `ownerHash`。本輪 `spotifyBrand.test.ts` 的手刻圖示測試換成官方 logo 測試。
