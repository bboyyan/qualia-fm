## 2. 行為變更（給審查者）

- **擁有者**：`qfm_spotify_owner`（HttpOnly、SameSite=Lax、Path=/、Max-Age 180 天、HTTPS 時 Secure）。綁裝置憑證不綁 session：session 過期或伺服器重啟仍有效。擁有者重新連結換新憑證；中斷連結清 cookie。
- **相容性**：BRA-111 前的 token 檔沒有擁有者雜湊 → 視為未連結（需重新連結）。目前從未啟用，影響為零。
- **拒絕的形狀**：未連結 → 403 `FEATURE_RESTRICTED`「請到設定重新連結」；已由別人連結 → 403 `FEATURE_RESTRICTED`「只有完成連結的擁有者能使用」。不呼叫 Spotify、不刪 token 檔、不洩漏擁有者資訊。
- **既有測試的預期改變（有意，非放寬）**：
  - `spotifyPlayback.test.ts`「沒有 Spotify 對應的段落、別人的節目、未啟用 → 不寫入」：別的 session 由 404 變 403（先被擁有者檢查擋下）。
  - `spotifyAuth.test.ts`「PKCE code_verifier」：改由同一擁有者連結兩次（別的 session 已不能覆蓋）。
  - `spotifyRace.test.ts` 6 案（P 路徑）：遲到那首回報已暫停後，先斷言「仍未安靜」，推進 500ms 才安靜（新的穩定時間）；`spotifyTokenStore.test.ts` 改帶 `ownerHash`。
- **UX 取捨**：路徑 C 被使用者暫停的歌直接切下一段時，介紹改等約 2 秒的靜音確認（原本立即開始）；路徑 P 只有在被切段的那首尚未確認在播時多等最多 0.5 秒。介紹中 Spotify 晚出聲 → 介紹改文字（D-17）。
