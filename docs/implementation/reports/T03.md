**User-visible behavior:**
- 「為我開台」→ 生成畫面：保留 Seed、四階段（理解你的感覺→配對相近的聲景→確認候選曲目→準備這一段節目）只在伺服器實際越過該 phase 才打勾，無百分比；「取消，保留我的輸入」；20 秒後顯示「這次找歌比較久」。
- Ready：節目已準備、Seed 摘要、感覺鉤子＋四面向精簡 chips（未知面向顯示「尚無資料，不做推測」）、「已準備 N 首 · MOCK 虛構曲目／尚未開始播放」、主動作「開始收聽」（T04 接上播放）。ready 不出聲、不跑進度。
- Partial（3 首）：如實「已確認 3 首，4 首候選暫時無法使用」＋「重新選歌」。
- 0 首：保留分析、列出「待確認」候選、「修改感覺」，不顯示播放器。
- 失敗：原因＋「再試一次」／「修改感覺」，輸入保留；SESSION_EXPIRED 時重試會先重建 session。
- 歌曲模式送出歌名＋藝人，mock 回覆明說「MOCK 不認識任何歌曲」（AC09）。
- 已有播放時文案改為「建立下一段」，並說明不會停止正在播放的這首（T04 起生效）。
