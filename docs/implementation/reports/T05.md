**User-visible behavior:**
- **Bridge sheet**（「完整理由」）：與起點的連結（seedBridge）、有實際相鄰前一首時另顯示「接續：前一首 → 這一首」、三個 vibe、感覺鉤子、Sonic DNA 四面向（未知顯示「尚無資料，不做推測」）、DJ 串詞文字、「重聽介紹（MOCK 提示音）」（重聽後從原位置繼續曲目）、可信度「推薦推測，尚未聽音驗證」。不觸發任何新生成。
- **Queue sheet**（「01/05」或「接下來」）：「這一段 · N 首」、每列順序／曲名／該位置實際成立的 Bridge／狀態（正在播放／已播／待播／已略過／無法播放）。正在播放的列不能移除；點列本身不換歌，只有「現在播放」會換；「移除」→ sheet 內 toast「復原」（5 秒）放回原位置；partial 時列出「暫時無法使用（不會播放）」候選。
- **Tune sheet**（「微調」）：「只調整接下來，不打斷這首」、四個快速方向（只填入）、短句（≤200 字、grapheme 計數）、「套用到接下來」。準備中顯示實際階段＋「取消（不改變任何曲目）」；完成後只替換目前這首之後的尾段，toast「已替換接下來的 5 首；這首沒有中斷。」；0 首則保留舊尾段；節目單在等待期間有變動 → 不自動套用，toast 提供「仍要套用」；節目已切換 → 捨棄。
- **Mini-player**：離開收聽頁且有節目時出現在底部導覽上方（不重疊、收聽頁不重複），顯示曲名＋真實狀態（如「MOCK 合成音播放中」），可暫停／播放、點一下回收聽頁。
- **設定**：DJ 開關即時生效（下一段起不再播介紹；介紹中關閉則直接進歌）、串詞長度、語音聲線（僅 MOCK 提示音）、播放環境與 Spotify 未啟用說明、音量用裝置鍵、資料說明、清除本機設定、MOCK 情境預覽（開台結果＋播放情境）。
- 已有節目時開台按鈕為「建立下一段」，生成期間原節目持續播放，ready 後才由使用者選「現在切換至新節目」或「先回到正在收聽」。
