**User-visible behavior:**
- Ready →「開始收聽」：同一個點擊內載入節目並開始播放。先播 DJ 介紹（合成提示音＋顯示串詞文字，標示「MOCK 提示音，非 AI 語音」），結束後播放**同一段**的 MOCK 合成測試音；進度來自 `<audio>` 實際位置。
- 收聽頁：節目脈絡＋01/05、抽象聲景（播放時才慢轉，reduced-motion 停用）、曲名／藝人＋「MOCK 虛構曲目」、vibe、短版 Bridge（「為什麼是這首」或「接續：前一首 → 這一首」）、DJ 串詞條＋「跳過介紹」、進度條（只有 track 階段可拖動，放開單次 seek）、重播本曲／64px 播放鍵／下一首、接下來＋微調入口。介紹期間播放鍵仍在首屏（360×800 起）。
- 暫停／繼續保留階段與位置，繼續播放不重念介紹；重播本曲回 0 且不念介紹；下一首連點每次只前進一首；自然播完只前進一次；最後一首結束 →「這一段節目聽完了」，不自動無限接續。
- 自動播放被擋（NotAllowedError）→「點一下，繼續這段節目」＋「點一下繼續」，不背景重試；曲目失敗最多自動略過 2 首，第 3 次停下顯示可恢復錯誤；裝置遺失 → reconcile →「重新連線」。
- 切換 tab 不重建音訊元件；回前景／pageshow 觸發 reconcile。

- E2E playback（每種手機寬度 8 案；以 init script 計算 `<audio>` 建立次數與同時播放數）：DJ→同段曲目且進度前進、介紹中無水平溢出且播放鍵在首屏、暫停凍結進度且恢復不重念、跳過介紹、**連點 3 次下一首：`<audio>` 只建立 1 個、同時播放數 ≤ 1**、重播本曲回 0:00、自然播完出現「接續：微光偏航 → 這一首」而跳過則回到 seedBridge、autoplay 被擋顯示點一下繼續、切 tab 後同一個 `<audio>` 仍在播放。
