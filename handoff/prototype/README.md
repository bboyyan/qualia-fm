# 手機互動參考原型

直接用瀏覽器開啟 `index.html`，不需要安裝、API 金鑰或網路。

這是畫面／互動參考，不是 production React 專案。全頁明示「互動原型・無音訊」，所有歌曲、封面聲景與描述都為虛構示意。沒有 Spotify、LLM、TTS、真實播放或持久儲存。使用者點擊範例 → 為我開台 → 開始收聽，可看到完整 mock 流程。

可操作：三個主頁、三種 Seed 輸入、模擬生成與取消、示意播放／暫停／重播／下一首／跳過介紹、Bridge 詳情、節目單／移除與復原、微調、DJ 開關、播放阻擋與離線情境預覽。原型微調只交換未播示意曲目；正式版依契約重建 tail。

UI 實作以 `docs/02_MOBILE_UX.md` 與 `docs/03_DESIGN_SYSTEM.md` 為準。原型不取代完整錯誤處理、鍵盤／螢幕閱讀器／真機播放驗收。原型計時器僅用於已標示的示範；不得搬到正式版假裝播放或生成完成。

色彩、spacing 與元件方向見 `design/tokens.*`。字型使用系統 fallback，不附字型檔。原創 SVG 是示意插畫，不是 Spotify 專輯封面，正式接入 artwork 須遵守來源規則。
