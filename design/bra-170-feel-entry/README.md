## 一句話設計摘要

開台畫面其他地方都不動。原本「感覺／歌曲／聲音」三格切換改成「從一首歌｜從一種感覺」兩格；選了感覺會出現 8 個情境標籤（兩行）和一句選填的自訂句，點一個標籤就能按「從「失戀」開台」。

## 畫面重點（對照截圖）

- **沿用原 UI**：Hero、卡片、主按鈕、底部提示、四格底部導覽、配色與字級都直接沿用現有樣式。色票逐字抄 `tokens.css`，沒有新增顏色，也沒有深色面。
- **入口二選一**：沿用 `.segmented` 外觀，只是改成兩格、高度 52px，文案寫成完整的動作句。選中那一格的圖示用 accent 色。
- **可切回從一首歌**：歌曲那格保留小數字徽章「1」，表示種子清單裡已勾選幾首。使用者一眼就知道切回去時清單還在，不會被清空。
- **情境標籤**：平靜、振奮、健身、失戀、深夜、通勤、專注、雨天。沿用 `.chip`，高 48px，排成 4 欄 × 2 行；選中的標籤加 ✓ 和 primary-wash 底色。採單選，再點一次就取消。
- **自訂一句**：「再補一句（選填，也可以只寫這句）」，沿用 `seedField`、計數和「不需要懂樂理」提示。
- **主按鈕跟著選擇改字**：有標籤時是「從「失戀」開台」；只有自訂句時是「為我開台」；已有節目在播時是「建立下一段」（同現行）。
- **拿掉的東西**：「聲音」入口（H1 定案不做），以及卡片下方那排範例 chips（「夜裡慢慢放鬆」等），因為情境標籤已經取代它們。
- **自檢（390×844）**：首屏從 Hero 到主按鈕和「5 首歌…」都看得到。主按鈕底緣約 y≈720，底部導覽頂緣約 y≈776，導覽不會蓋到按鈕。觸控尺寸：入口 52px、標籤 48px、主按鈕 56px、導覽 64px，全部 ≥44px。

## 用戶流程

**A. 從一首歌**（行為與 BRA-117／BRA-156 相同）

1. 進開台 tab，預設停在「從一首歌」，看到種子清單（預設種子＋我的歌收藏／釘選）。
2. 勾選或取消勾選；要的話輸入歌名和藝人，按「加入清單並勾選」。
3. 按「全選・快速開台」或「快速開台（已選 X／N）」。
4. 進入生成畫面，接著到 Ready（5 首）後開始收聽。

**B. 從一種感覺**

1. 進開台 tab，點「從一種感覺」（歌曲清單的勾選保留，徽章會顯示數量）。
2. 點一個情境標籤，例如「失戀」，主按鈕立刻變成「從「失戀」開台」。
3. （選填）在「再補一句」寫一句自己的情境；不選標籤、只寫這句也可以。
4. 按主按鈕，進入生成畫面，接著到 Ready 後開始收聽。

## 感覺入口送出時怎麼進選歌輸入（給 V2 實作的建議，本輪不實作）

**原則**：不改 API 契約，沿用 `seed.kind = 'feeling'` 和 `seed.text`（≤500 字）。

1. **前端常數 `MOOD_PRESETS`**（放在 `seedList.ts` 旁）：每個標籤是 `{ id, label, prompt }`。`prompt` 是給選歌的一句描述，例如：
   - 失戀 → 「失戀後的心情：有點空、溫柔，慢慢走出來」
   - 健身 → 「運動時穩定推進的節奏與能量」
   
   label 給人看，prompt 給模型看。
2. **組 `seed.text`**（在 `toPlanRequest` 的 feeling 分支）：
   - 只有標籤：`prompt`
   - 標籤＋自訂句：`` `${prompt}。${自訂句}` ``（使用者的句子放後面，語氣以使用者為準）
   - 只有自訂句：照現況送 `text.trim()`
3. **畫面回顯**：生成畫面的 `seedQuote`、開台歷史（BRA-148）建議顯示 `「失戀」下班一個人走回家…`，也就是 label＋原句，不顯示 prompt。實作上要另外存 `moodId`，或從 text 反查。
4. **之後再做**：如果要讓後端看得出這次是「標籤開台」（例如做統計或給不同權重），再在契約加選填欄位 `seed.mood`。不要借用 `tuning` 欄位，它是重新調整用的。
5. **驗證**：標籤和自訂句至少要有一個，否則主按鈕停用，沿用 `draftProblem`。組出來的 text 仍然受 500 字上限限制；因為 prompt 很短，實際上只要限制自訂句的長度。

## H1 要曄看的重點

1. **兩格的文案和順序**：「從一首歌」在左、當預設；「從一種感覺」在右。要不要反過來讓感覺當預設？
2. **8 個情境標籤的選詞**：平靜、振奮、健身、失戀、深夜、通勤、專注、雨天。要換掉或增減哪幾個？維持兩行（最多 8 個）是否 OK？
3. **單選 vs 可複選**：目前是單選，最直覺；複選（例如「深夜＋失戀」）會讓按鈕文案和組句變複雜。
4. **主按鈕文案**：「從「失戀」開台」是否 OK，還是統一用「為我開台」？
5. **拿掉卡片下方的範例 chips**：這個 OK 嗎？已經由情境標籤取代。
6. **歌曲那格的數字徽章**：要保留（提示切回去清單還在），還是拿掉讓畫面更乾淨？
7. **組句規則**：`prompt＋自訂句`、畫面回顯只用 label，這個方向是否 OK？
