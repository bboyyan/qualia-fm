## Hero 文案

**採用**：

> 從一首歌，或一種感覺，
> 開始探索你的人生終極曲目。

- 最接近曄給的原話，只在「或一種感覺」前後加逗號，讓它斷成兩行、讀起來有停頓。
- 第一行和下方兩個入口「從一首歌｜從一種感覺」字面一致，使用者讀完引言，眼睛往下就看到同樣兩個選擇。
- 390 寬時兩行分別 11 字和 13 字，都在原本 `max-width: 330px` 內，不會擠或多斷一行（見截圖）。
- h1「不是同類型。是同一種感覺。」講的是推薦怎麼連（同一種感覺，不是同曲風）；引言講的是從哪裡開始、要找什麼，兩者不衝突，所以 **h1 與 Eyebrow 都不改**。

**備選**：

1. 「一首歌、一種感覺，都能是起點。／慢慢找出你的人生終極曲目。」：比較口語、溫和，但跟入口按鈕的字面沒有對齊。
2. 「從一首歌或一種感覺出發，／一路聽見你的人生終極曲目。」：「一路聽見」比較有電台感，但「聽見曲目」的搭配有點虛。

## 範例 chips 與情境標籤：分工與互動

| | 情境標籤（8 個） | 範例 chips（常用的一句感受） |
| --- | --- | --- |
| 是什麼 | 場景／類別 | 一句現成的感受，算是「再補一句」的捷徑 |
| 選法 | 單選，再點取消 | 點一下就把「再補一句」換成這句；再點同一個就清空這一欄 |
| 決定什麼 | `seed.text` 的主體（標籤的 `prompt`） | `seed.text` 的後半句（自訂句） |
| 會不會直接開台 | 不會 | 不會，只會填入 |
| 位置 | 卡片內，「從一種感覺」才出現 | 卡片下方，兩種模式都看得到（同現行位置） |

規則：

1. **措辭不和標籤重複**：沿用現行三句「夜裡慢慢放鬆」「想找回一點精神」「陪我安靜走一段」，沒有任何一句和 8 個標籤字面相同（e2e 現有的「夜裡慢慢放鬆」也不用改）。
2. **在「從一首歌」模式**：chips 照樣顯示，小標寫「・點了會切到「從一種感覺」」。點了以後會切到「從一種感覺」並填入「再補一句」，但不會幫你選標籤，也不會開始；歌曲清單的勾選保留。這和現行 `setDraft({ kind: 'feeling', text })` 的行為一致。
3. **在「從一種感覺」模式**：小標寫「・點了填入「再補一句」」。點了以後，chip 句會**取代**目前的自訂句（沿用現行行為，不做附加，避免句子越疊越長）；目前的句子剛好等於某個 chip 時，那個 chip 顯示為選中。
4. **可以和標籤並用**：例如標籤「深夜」＋chip「夜裡慢慢放鬆」→ `深夜獨處：安靜、貼近耳邊，不吵醒誰。夜裡慢慢放鬆`（可開 `#feel-chip` 看）。
5. **之後再做**：用使用者最近用過的自訂句取代預設三句（本機最近 3 句，去重）。本輪不做。

| 任意 | 任意 | 任意 | 送出中顯示 loading | 同左 | — | 沿用 `Button loading` |

- **只寫自訂句時用「為我開台」，不用「從這句話開台」**：這是現行文案，e2e 和使用者都熟悉；而且這句話可能是點 chip 帶進來的，不一定是「你寫的這句話」；字數也比較短。
- **全空時停用按鈕，不另外跳錯誤**：原因直接寫在按鈕正上方的預覽區（之後實作時，按鈕可以用 `aria-describedby` 指到它），使用者不用按了才知道哪裡不行。
- **「建立下一段」的併法**：規則和現在一樣，有節目在播時把動詞「開台」換成「建立下一段」。有標籤時保留「從「X」」，讓使用者知道下一段會往哪個方向接。

## 組句與完整顯示

**不改 API 契約**：沿用 `seed.kind = 'feeling'`、`seed.text ≤ 500 字`、`seed.artist = null`。

1. **`MOOD_PRESETS`**（前端常數，放在 `seedList.ts` 旁）：`{ id, label, prompt }`，label 給人看，prompt 給選歌用。稿中用的 prompt：

   | label | prompt |
   | --- | --- |
   | 平靜 | 平靜下來的心情：放慢呼吸，柔和、多一點留白 |
   | 振奮 | 想被振奮：明亮、有推進感，讓人想動起來 |
   | 健身 | 運動時穩定推進的節奏與能量 |
   | 失戀 | 失戀後的心情：有點空、溫柔，慢慢走出來 |
   | 深夜 | 深夜獨處：安靜、貼近耳邊，不吵醒誰 |
   | 通勤 | 通勤路上：順順地往前走，不打擾思緒 |
   | 專注 | 需要專注：穩定、少人聲，不搶注意力 |
   | 雨天 | 雨天的氣氛：潮濕、慵懶，帶一點溫度 |

2. **組 `seed.text`**：
   - 只有標籤：`prompt`
   - 標籤＋自訂句：`` `${prompt}。${自訂句.trim()}` ``（例：`失戀後的心情：有點空、溫柔，慢慢走出來。下班一個人走回家`）
   - 只有自訂句：`自訂句.trim()`（同現況）
3. **開台頁完整顯示**：主按鈕上方的「這次開台會用」**就是**上面組出來的 `seed.text` 原文，沒有另外改寫；會換行、不截斷，樣式沿用生成畫面 `.seedQuote` 的左線。字數計數（`28 / 500`）算的是組好的全文，因為 500 字上限是對全文檢查的。選標籤時計數會跳一下，這是預期中的行為。
4. **改掉 v1「畫面回顯只用 label」**：生成畫面、Ready、開台歷史、收聽頁都直接顯示 `seed.text` 全文，所以 **不需要另外存 `moodId`，也不用從 text 反查**。現有程式本來就是顯示 `seed.text`，只要處理截斷：
   - 生成畫面／Ready 的 `.seedQuote`：拿掉 `-webkit-line-clamp: 4`，改成完整顯示。
   - 開台歷史（BRA-148）：`<h2>{show.seed.text}</h2>` 和詳情裡的「種子：感覺・…」已經是全文，不用改。
   - 收聽頁 `.seedLine` 是單行省略，空間有限，建議維持；完整內容在生成畫面和歷史都看得到。
5. **之後再做**：如果後端需要分辨「標籤開台」（例如統計或給不同權重），再在契約加選填的 `seed.mood`，不要借用 `tuning`。

## 用戶流程

**A. 從一首歌（預設，同 BRA-117／156）**

1. 進開台 tab，停在「從一首歌」，看到種子清單。
2. 勾選或加入歌，按「全選・快速開台」或「快速開台（已選 X／N）」。
3. 進入生成畫面，到 Ready 後開始收聽。

**B. 從一種感覺**

1. 點「從一種感覺」（歌曲清單的勾選保留，只是不顯示徽章）。
2. 點一個情境標籤，例如「失戀」，主按鈕變成「從「失戀」開台」，預覽區出現 prompt 全文。
3. （選填）在「再補一句」寫一句，或點「常用的一句感受」帶入一句，預覽區同步更新成完整組句。
4. 確認預覽沒問題後按主按鈕，生成畫面引用的是同一段全文。

**C. 從 chip 直接進入**

在「從一首歌」模式點了 chip →切到「從一種感覺」並填入這句 → 主按鈕是「為我開台」，也可以再選一個標籤，變成「從「X」開台」。
